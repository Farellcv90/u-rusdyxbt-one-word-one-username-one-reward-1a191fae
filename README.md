farellcv90

## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly `farellcv90` — 10 bytes, no trailing newline — to `/output/entry.txt`, creating `/output` if needed. A small guard in the code throws if the username ever stopped being valid UTF-8, 1–30 characters, a single word with no whitespace.

Run it with:

```sh
node main.ts
```
